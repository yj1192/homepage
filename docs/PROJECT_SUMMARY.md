# AI小白杨 - 科技感个人主页

## 项目概述

这是一个充满科技感的个人主页网站，采用深色主题和炫酷的渐变效果，完美展示个人品牌形象和专业能力。

## 核心特性

### 🎨 视觉设计
- **科技感配色**：深蓝到紫色的主渐变，搭配青色和粉色的辅助色
- **发光效果**：卡片和按钮带有动态发光效果，营造未来感
- **流畅动画**：悬浮、脉冲、渐变等多种动画效果
- **响应式布局**：完美适配桌面和移动设备

### 📱 功能模块

1. **Hero区域**
   - 个人头像（渐变圆环设计）
   - 姓名和职位展示
   - 个人简介
   - CTA按钮（联系我、查看作品）
   - 滚动提示动画

2. **关于我**
   - 项目经验展示
   - 荣誉认证列表
   - 卡片式布局，带发光效果

3. **专业技能**
   - 5项核心技能展示
   - 动态进度条（带闪光动画）
   - 技能等级百分比
   - 彩色图标分类

4. **项目作品**
   - 3个主要项目展示
   - 项目描述和标签
   - 悬浮放大效果
   - 查看详情按钮

5. **联系方式**
   - 微信、邮箱、小红书、公众号
   - 一键复制功能
   - 发送邮件快捷按钮
   - 版权信息

## 技术栈

- **框架**: React 18 + TypeScript
- **样式**: Tailwind CSS + 自定义CSS变量
- **UI组件**: shadcn/ui
- **图标**: Lucide React
- **构建工具**: Vite
- **代码规范**: Biome

## 设计系统

### 颜色变量
```css
--primary: 262 83% 58%        /* 主色：紫色 */
--secondary: 187 100% 50%     /* 辅助色：青色 */
--accent: 330 100% 63%        /* 强调色：粉色 */
--background: 240 100% 2%     /* 背景：极暗黑 */
```

### 渐变效果
- `gradient-primary`: 紫色渐变
- `gradient-secondary`: 青紫渐变
- `gradient-accent`: 粉紫渐变

### 发光效果
- `glow-effect`: 紫色发光
- `glow-cyan`: 青色发光
- `glow-pink`: 粉色发光

### 动画
- `animate-float`: 浮动动画
- `animate-pulse-glow`: 脉冲发光
- `animate-shimmer`: 闪光效果

## 交互功能

1. **平滑滚动**: 点击按钮平滑滚动到对应区域
2. **复制功能**: 点击联系方式卡片自动复制信息
3. **邮件发送**: 快速打开邮件客户端
4. **悬浮效果**: 卡片悬浮时上浮并增强发光
5. **响应式**: 自适应不同屏幕尺寸

## 性能优化

- 使用CSS变量统一管理设计系统
- 动画使用transform和opacity，避免重排
- 合理使用pointer-events避免事件冲突
- 响应式图片和懒加载
